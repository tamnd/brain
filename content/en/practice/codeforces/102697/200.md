## Solution
## Problem Understanding

We have at most seven pins fixed at integer coordinates in the plane. We choose some of those pins and stretch a rubber band around the chosen set. A taut rubber band around a collection of points follows the boundary of their convex hull. The chosen pins must all be touched by the band, and there must not be any other pin strictly inside the band. Pins lying directly on the band are harmless because they are touching it.

The task is to maximize the number of chosen pins satisfying those two geometric conditions. The official input bound is only (n \le 7), with a 1 second time limit and 256 MB of memory. This is extremely small, so an exponential algorithm over subsets is entirely reasonable. There are at most (2^7=128) subsets, and even doing several (O(n^2)) geometric checks for every subset is negligible.

The main edge cases come from points that are collinear or lie strictly inside a convex hull. For example,

```
3
0 0
1 0
2 0
```

has answer `3`. All three pins lie on the boundary of the degenerate convex hull, so the band can touch all of them.

A more dangerous case is an interior point:

```
5
0 0
4 0
2 2
2 -2
2 0
```

The four points other than `(2, 0)` form the outer diamond, while `(2, 0)` is strictly inside it. Choosing all five pins is impossible because the inner pin would not touch the band. The correct answer is `4`.

A point on a hull edge must not be confused with an interior point. For example,

```
6
0 0
2 0
4 0
2 2
2 -2
3 -1
```

has answer `5`. The point `(3, -1)` lies on the edge from `(4, 0)` to `(2, -2)`, so the rubber band touches it. Treating every non-vertex of a standard convex hull implementation as an interior point would incorrectly reject this configuration.

## Approaches

The direct brute force is already the right approach because the input is tiny. We can enumerate every subset of pins, pretend that this is the set around which we stretch the rubber band, compute its convex hull, and check whether that subset is valid.

For a subset to work, every selected point must lie on the boundary of its convex hull. Otherwise that selected point would be strictly inside the rubber band and would not be touched. We also inspect every pin that was not selected. If such a pin is strictly inside the convex hull, the subset is invalid because the rubber band encloses a pin without touching it. A pin on the boundary is allowed, even if we did not explicitly choose it.

The brute-force search considers (2^n) subsets. For each subset, a hull can be constructed in (O(n\log n)), and because (n\le7), even a simpler (O(n^2)) geometric check is more than fast enough. In the worst case we perform only a few thousand primitive orientation tests.

The useful observation is that there is no need to search over the infinitely many possible shapes of a rubber band. Once the selected pins are fixed, the taut band is completely characterized by their convex hull. Geometry reduces the original physical description to two finite checks: selected points must be on the hull boundary, and no unselected point may be strictly inside the hull.

| Approach | Time Complexity | Space Complexity | Verdict |
| --- | --- | --- | --- |
| Brute Force over subsets | (O(2^n n^2)) | (O(n)) | Accepted |
| Optimal subset enumeration with convex hull checks | (O(2^n n^2)) | (O(n)) | Accepted |

For this problem, the second row is effectively the intended solution. There is no need for a more complicated asymptotic technique because (n) is at most seven.

## Algorithm Walkthrough

1. Read all pin coordinates and represent each pin by its index and its coordinate pair. Keeping the indices matters because two different pins could occupy the same coordinate.
2. Enumerate every nonempty subset of the (n) pins. Since (n\le7), there are at most 127 subsets to inspect.
3. Extract the points belonging to the current subset and compute their convex hull. Use a monotone-chain hull, but retain collinear points on hull edges rather than discarding them. A point on an edge is physically touched by the rubber band, so it must count as a boundary point.
4. Check every selected point against the hull boundary. If even one selected point is strictly inside the hull, reject this subset. For a one-point subset the point itself is the boundary. For two or more collinear points the hull is a segment, and every point on that segment is on the boundary.
5. Check every unselected pin. If it is strictly inside the convex hull, reject the subset. If it is outside or lies on the hull boundary, it does not violate the condition.
6. If both checks pass, update the answer with the size of the subset. Since subsets are independent, keeping the largest valid size directly gives the required maximum.

### Why it works

For a fixed selected set (S), the taut rubber band is the boundary of (\operatorname{conv}(S)). A selected point is touched exactly when it lies on that boundary. An unselected pin violates the condition exactly when it lies strictly inside the convex hull, because then the band surrounds it without touching it. The algorithm checks precisely these two necessary and sufficient properties for every possible selected set. Since every candidate subset is examined, the largest accepted subset is the optimal answer.

## Python Solution

```python
import sys
input = sys.stdin.readline

def cross(a, b, c):
    return (b[0] - a[0]) * (c[1] - a[1]) - (b[1] - a[1]) * (c[0] - a[0])

def convex_hull(points):
    """Return the hull boundary as an ordered list.

    Collinear points on an edge are kept.
    Duplicate coordinates are removed for geometric construction.
    """
    points = sorted(set(points))

    if len(points) <= 1:
        return points

    lower = []
    for p in points:
        while len(lower) >= 2 and cross(lower[-2], lower[-1], p) < 0:
            lower.pop()
        lower.append(p)

    upper = []
    for p in reversed(points):
        while len(upper) >= 2 and cross(upper[-2], upper[-1], p) < 0:
            upper.pop()
        upper.append(p)

    return lower[:-1] + upper[:-1]

def on_segment(a, b, p):
    return (
        cross(a, b, p) == 0
        and min(a[0], b[0]) <= p[0] <= max(a[0], b[0])
        and min(a[1], b[1]) <= p[1] <= max(a[1], b[1])
    )

def on_boundary(hull, p):
    if len(hull) == 0:
        return False

    if len(hull) == 1:
        return p == hull[0]

    for i in range(len(hull)):
        if on_segment(hull[i], hull[(i + 1) % len(hull)], p):
            return True

    return False

def strictly_inside(hull, p):
    """Whether p lies strictly inside the polygonal hull."""
    if len(hull) < 3:
        return False

    if on_boundary(hull, p):
        return False

    sign = 0
    m = len(hull)

    for i in range(m):
        c = cross(hull[i], hull[(i + 1) % m], p)

        if c == 0:
            return False

        if sign == 0:
            sign = 1 if c > 0 else -1
        elif (c > 0 and sign < 0) or (c < 0 and sign > 0):
            return False

    return True

def solve():
    n = int(input())
    points = [tuple(map(int, input().split())) for _ in range(n)]

    answer = 1

    for mask in range(1, 1 << n):
        chosen = [points[i] for i in range(n) if mask & (1 << i)]

        if len(chosen) <= answer:
            continue

        hull = convex_hull(chosen)

        # Every selected pin must be on the rubber band's boundary.
        valid = True
        for p in chosen:
            if not on_boundary(hull, p):
                valid = False
                break

        if not valid:
            continue

        # An unselected pin may be outside or on the band,
        # but never strictly inside it.
        for i, p in enumerate(points):
            if mask & (1 << i):
                continue

            if strictly_inside(hull, p):
                valid = False
                break

        if valid:
            answer = len(chosen)

    print(answer)

if __name__ == "__main__":
    solve()
```

The `cross` function computes the signed area of the triangle formed by three points. Its sign tells us whether the third point is to the left or right of a directed edge, and zero means that the three points are collinear.

The hull construction sorts the coordinates and builds the lower and upper chains. The usual monotone-chain implementation often uses `<= 0` when removing points, which discards collinear points. That would be wrong here because a pin lying on a straight section of the rubber band is still touched. The implementation consequently removes a point only when the turn is strictly clockwise.

The `on_boundary` function deliberately checks the actual hull segments instead of asking whether a point is one of the hull vertices. This handles collinear pins correctly and also handles the degenerate one-point and two-point cases.

The `strictly_inside` function is only meaningful for a two-dimensional hull. For a segment or a single point there is no positive-area interior, so it returns false. For a polygon, a point is strictly inside when it lies on the same strict side of every directed hull edge. A boundary point is explicitly rejected from the interior test.

The subset loop skips subsets no larger than the current answer. Such a subset cannot improve the result, so there is no reason to perform its geometric checks. All arithmetic uses Python integers, so there is no overflow issue regardless of the coordinate magnitude.

## Edge Cases

For a single pin,

```
1
7 -3
```

the selected set has one point and its convex hull is that point. There is no positive-area interior, so the point is valid and the answer is `1`.

For collinear points,

```
5
0 0
1 0
2 0
3 0
4 0
```

the hull degenerates into the segment from `(0,0)` to `(4,0)`. The boundary check treats every point on that segment as touched, so all five pins can be selected and the answer is `5`.

For coincident pins,

```
4
3 3
3 3
3 3
3 3
```

the geometric hull contains only one coordinate, but the original pins are still four distinct selectable pins. The boundary check compares coordinates rather than requiring distinct hull vertices, so all four pins are accepted.

For an interior point,

```
5
0 0
4 0
2 2
2 -2
2 0
```

the four outer points form a diamond and `(2,0)` is strictly inside it. If all five pins are selected, the selected interior pin fails the boundary check. Selecting only the four outer points succeeds, giving answer `4`.

For a point on a hull edge,

```
5
0 0
4 0
4 4
0 4
2 0
```

the point `(2,0)` is collinear with `(0,0)` and `(4,0)`. It is on the rubber band's boundary rather than inside it. The hull implementation preserves this collinear point, and `on_segment` recognizes it as boundary, so all five pins are valid and the answer is `5`.
