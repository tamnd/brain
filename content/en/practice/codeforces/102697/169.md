## Solution
## Problem Understanding

The problem is the game **SOS** from Codeforces Gym 101775, Problem L. The board is a row of (N) empty cells. Panda moves first, and the players alternate by choosing an empty cell and writing either `S` or `O` into it. The moment a move creates three consecutive cells spelling `SOS`, the player who made that move wins. If every cell is filled without producing `SOS`, the result is a draw.

The input contains up to (1000) independent games, and (N) is at most (1000). Since the answer depends only on (N), not on an actual sequence of moves, the intended solution should be essentially constant time per test case. Any simulation that explores the game tree is hopeless. Even if we only count complete move sequences, there can be (2^N N!) of them, because every move chooses one of the remaining cells and one of two letters. A two-second limit makes even polynomial simulation unnecessary once the structure of the game is understood.

The crucial edge case is the very small board. For (N=3), Panda cannot force a win because Panda gets only the first move and Sheep can always prevent the final three cells from becoming `SOS`. The correct result is `Draw`. For example, the input

```
1
3
```

produces

```
Case #1: Draw
```

A careless approach that assumes three cells are enough to make `SOS` would incorrectly declare Panda the winner, ignoring that Sheep gets the second move.

Another boundary occurs at (N=7). Here Panda can force a win, while (N=6) is still a draw. Thus

```
1
6
```

produces

```
Case #1: Draw
```

but

```
1
7
```

produces

```
Case #1: Panda
```

The difference is not simply the parity of (N). The board needs at least seven consecutive available positions for the central winning construction to work.

There is a second, less obvious boundary at (N=16). Even board lengths from (8) through (14) are draws, but (16) is a Sheep win. Thus

```
1
14
```

gives `Draw`, whereas

```
1
16
```

gives `Sheep`. The first move on an even board has to avoid giving the opponent a winning structure, and at length (16) Sheep finally has enough room to create a seven-cell winning region after Panda's defensive move.

## Approaches

A direct solution would model the entire game. At every position, try every empty cell and both possible letters, recursively determine whether the current player can force a win, and stop when `SOS` appears. This is correct because every legal move is considered, so minimax can distinguish winning, losing, and drawing positions. The problem is the size of the tree. Without pruning, the number of complete play sequences is (2^N N!). Even a memoized representation of the board has up to (3^N) states, since every cell can be empty, `S`, or `O`. For (N=1000), neither approach is remotely feasible.

The useful observation is that the game has a tiny local winning pattern. Consider four consecutive cells in the form `S__S`, where the two middle cells are empty. Whoever has the move in this position loses immediately. If that player writes `O` in either empty cell, the opponent writes `S` in the other cell and obtains `SOS`. If that player writes `S` in one empty cell, the opponent writes `O` in the other and again obtains `SOS`. Thus `S__S` is a trap for the player whose turn it is.

The next question is how to force this trap. Seven consecutive empty cells are enough. Put `S` in the fourth cell. Wherever the opponent moves inside those seven cells, choose the endpoint on the opposite side and put another `S` there. The two cells between the two `S` characters remain empty, producing `S__S`. If the opponent plays outside the seven-cell region, the same construction is even easier because either endpoint can be chosen.

This seven-cell construction explains the odd-board result. On an odd board of length at least seven, Panda can create such a region first and use the parity of the remaining moves to force Sheep to face the trap. Hence every odd (N\ge7) is a Panda win.

For even (N), Panda cannot use the same winning construction safely, because the parity reverses who eventually has to move in the trap. Panda instead starts with `O`, splitting the board into two sides. For (N<16), Panda can choose the position of that `O` so that both sides have fewer than seven cells. Sheep can no longer create the seven-cell forcing region, and neither player can force a win, giving a draw.

At (N=16), Panda can no longer split the board into two regions both shorter than seven. No matter where the first `O` is placed, one side contains at least seven cells. Sheep can exploit that side using the same seven-cell construction. The same argument applies to every larger even (N), so Sheep wins for all even (N\ge16). This yields the complete classification

[
\text{Panda if }N\text{ is odd and }N\ge7,
]

[
\text{Sheep if }N\text{ is even and }N\ge16,
]

and `Draw` otherwise. This classification is also the one used by accepted solutions for the problem.

## Algorithm Walkthrough

1. Read (N). The actual board never needs to be constructed because the winner is determined solely by the length of the board.
2. If (N) is odd and (N\ge7), output `Panda`. A seven-cell region lets the first player create the `S__S` trap, and odd parity makes the trap favorable to the player who created it.
3. Otherwise, if (N) is even and (N\ge16), output `Sheep`. Panda's first defensive `O` cannot split a board of this size into two regions shorter than seven, so Sheep can obtain a seven-cell region and reverse the same construction.
4. For every remaining value of (N), output `Draw`. This covers every (N\le6), where the winning construction does not fit, and every even (N) from (8) through (14), where Panda can prevent either player from obtaining a sufficiently large region.

The reason the classification works is the `S__S` invariant. Once a player is forced to move inside `S__S`, every possible letter loses immediately on the opponent's next move. Seven consecutive empty cells are precisely enough to create this structure despite one opponent move, which gives the threshold at seven. The parity of the board then determines which player can force the opponent to be the one who moves in the trap. The even case needs enough space on both sides of Panda's first defensive move, producing the second threshold at sixteen.

## Python Solution

```python
import sys
input = sys.stdin.readline

def solve():
    t = int(input())

    for case in range(1, t + 1):
        n = int(input())

        if n >= 7 and n % 2 == 1:
            result = "Panda"
        elif n >= 16 and n % 2 == 0:
            result = "Sheep"
        else:
            result = "Draw"

        print(f"Case #{case}: {result}")

if __name__ == "__main__":
    solve()
```

The solution first reads the number of games, then handles each board independently. The first condition checks the odd winning range, (7,9,11,\ldots). The second condition checks the even winning range, (16,18,20,\ldots). Every value not covered by either condition is a draw.

The order of the conditions is not technically dangerous because the two ranges are disjoint, but writing them directly from the mathematical classification makes the implementation easy to verify. There are no arrays, recursion, or board simulation, so there are no boundary indices to manage and no integer overflow concerns. Python's integer type is more than sufficient for the input range.

The output uses the required `Case #x: result` format, with case numbering beginning at one, exactly as specified by the original problem.

## Edge Cases

For (N=1), the board contains only one cell, so forming three consecutive characters is impossible. The algorithm reaches neither winning condition and prints `Draw`.

For (N=6), the board is still too short to contain the seven-cell forcing region. The algorithm checks `n >= 7`, finds it false, and prints `Draw`. This catches the common off-by-one error of using (N>7) instead of (N\ge7), or treating (N=6) as a winning position.

For (N=7), Panda gets exactly the seven cells required for the central construction. Panda can place `S` in the fourth cell, and after Sheep's move, Panda chooses the opposite endpoint to create `S__S`. Since either move in that trap allows the opponent to complete `SOS`, Sheep cannot escape the losing position. The algorithm therefore prints `Panda`.

For (N=14), the board is even but still below the Sheep threshold. Panda can start with `O` in a suitable central position so that the remaining portions are too short for Sheep to establish the seven-cell forcing structure. The result is `Draw`.

For (N=16), that defensive strategy stops working. Wherever Panda places the initial `O`, at least one side has seven or more cells. Sheep can use such a region to reproduce the seven-cell construction, so the second player has a forced win. The algorithm prints `Sheep`.

For (N=1000), the board is even and well above sixteen, so the answer is also `Sheep`. No simulation is performed, which is why the large input is no harder than (N=16).
